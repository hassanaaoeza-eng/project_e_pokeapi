Student Workflow

  1. Open this docs page.
  2. Open one real PokeAPI example in the browser.
  3. Complete one small TODO method at a time.
  4. Refresh http://localhost:8000/api/pokemon to check the roster.
  5. Use the frontend on port 5173 to test the game flow.

Fields To Extract

id

data["name"]

display name

data["name"].title()

first type

data["types"][0]["type"]["name"]

sprite

data["sprites"]["front_default"]

stats

self._stats_by_name(data)

Use the keys hp, attack, defense, and speed.

moves

STARTER_MOVE_IDS
MOVE_LIBRARY

Do not parse PokeAPI move data for this lesson.

Provided Boilerplate

File

backend/engine/pokeapi_client.py

Helper

self._get_json(path)

This helper adds the base PokeAPI URL, makes the HTTP request, checks for HTTP errors, and returns a Python dictionary.

Students only choose the path and pass the result forward.

Challenge Map

1. Fetch One Pokemon

PokeApiClient.fetch_pokemon()

  • build /pokemon/{pokemon_id}
  • call self._get_json(path)
  • return self.build_pokemon(data)

2. Build One Pokemon Object

PokeApiClient.build_pokemon()

  • read name, type, sprite, and stats
  • call self.build_moves(pokemon_id)
  • return Pokemon(...)

3. Build Moves

PokeApiClient.build_moves()

  • read STARTER_MOVE_IDS
  • look up each id in MOVE_LIBRARY
  • use a list comprehension

4. Build The Roster

PokeApiClient.fetch_roster()

  • loop through ROSTER_IDS
  • call self.fetch_pokemon(...)
  • use a list comprehension

5. Create Battle Pokemon

BattlePokemon.from_pokemon()

  • store the original Pokemon
  • start current HP at full HP
  • return BattlePokemon

6. Create Battle State

Battle.create()

  • create player and enemy battle objects
  • use speed to choose first turn
  • return a Battle

7. Return Battle State

Battle.to_dict()

  • return battleId, player, enemy
  • return turn, log, winner

8. Process One Move

Battle.apply_move()

  • check whose turn it is
  • find the selected move
  • lower HP and switch turns

9. Build Damage

calculate_damage()

  • use move power
  • use attack and defense
  • use type effectiveness
  • return at least 1 damage

10. Detect The Winner

Battle.apply_move()

  • check for 0 HP
  • set winner
  • block future moves after the battle ends

  "name": "string",
  "type": "string",

  "name": "Pikachu",
  "type": "electric",
  "sprite": "image URL",
  "hp": 90,
  "attack": 55,
  "defense": 40,
  "speed": 90,
  "moves": [...]

{
  "battleId": "string",
  "player": {...},
  "enemy": {...},
  "turn": "player",
  "log": [],
  "winner": null
}

Common Mistakes

  • Trying to edit frontend JavaScript for a Python backend challenge.
  • Opening backend API routes on port 5173 instead of port 8000.
  • Parsing all PokeAPI moves instead of using STARTER_MOVE_IDS and MOVE_LIBRARY.
  • Returning raw PokeAPI dictionaries instead of Pokemon objects.
  • Using the whole types list when this beginner project only needs the first type.
